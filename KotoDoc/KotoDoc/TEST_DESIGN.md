# KotoDoc テスト設計書

本ドキュメントは、KotoDoc（メモ管理アプリケーション）の機能検証および品質担保を目的としたテスト仕様書です。

## 1. テスト対象機能
1. メモ一覧表示機能
2. メモ詳細表示機能（Markdownレンダリング含む）
3. メモ新規作成機能
4. タグ絞り込み・キーワード検索機能

---

## 2. 単体・統合テスト観点 (JUnit / Backend)

### 2.1 Service / Repository 層
- [ ] **メモ保存**: 正常なデータ（タイトル・本文・タグ）を入力した際、DBへ正しく永続化されること。
- [ ] **全件取得**: 登録済みのメモが作成日時の降順（新しい順）で取得できること。
- [ ] **ID指定取得**: 存在しないIDを指定した際、適切な例外（またはEmpty）が返却されること。
- [ ] **タグ検索**: 指定したタグが含まれるメモのみが抽出できること。
- [ ] **キーワード検索**: タイトルおよび本文に検索ワードが含まれるメモが抽出できること（部分一致）。

---

## 3. 画面結合・E2Eテスト観点 (UI / Frontend)

### 3.1 一覧画面 (`/`)
- [ ] 画面アクセス時、保存済みのメモ一覧がカード形式で表示されること。
- [ ] メモがない場合、空の文言または適切なメッセージが表示されること。
- [ ] 「+ メモを書く」ボタンを押下すると、作成画面へ遷移すること。

### 3.2 詳細画面 (`/memos/{id}`)
- [ ] メモ本文に記述されたMarkdown（見出し、箇条書き、テーブル等）がHTMLとして正しく変換・表示されること。
- [ ] 存在しないIDのURLにアクセスした際、エラーページまたは一覧へ安全にリダイレクトされること。

### 3.3 新規作成画面
- [ ] タイトルと本文を入力して送信すると、メモが作成されて一覧画面（または詳細画面）へ遷移すること。
- [ ] 必須項目（タイトル・本文）が未入力の場合、バリデーションエラーが表示され送信できないこと。
- [ ] カンマ区切りで入力したタグ（例: `Java,SpringBoot`）が個別のタグバッジとして表示されること。

### 3.4 検索機能
- [ ] 検索窓にキーワードを入力して検索を実行すると、該当するメモのみが表示されること。
- [ ] 画面上のタグバッジをクリックした際、そのタグで絞り込まれた一覧が表示されること。

---

## 4. 境界値・異常系テスト観点
- [ ] **長文テキスト**: `content` に非常に長い文章（数万文字など）を入力してもDBエラーにならず保存できること（CLOB型の検証）。
- [ ] **特殊文字**: タイトルや本文に `<script>` などのHTML/JSコードを含めた際、XSS（クロスサイトスクリプティング）が発生せず安全にエスケープ表示されること。
- [ ] **空文字タグ**: タグ入力欄にスペースのみや連続したカンマを入力した場合でも、エラーにならず正しく処理されること。
