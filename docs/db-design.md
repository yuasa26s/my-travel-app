## schedules（タイムライン / 予定）

| フィールド名 | 型       | 説明               |
| ------------ | -------- | ------------------ |
| id           | number   | 予定ID（自動採番） |
| tripId       | number   | 旅行ID             |
| date         | string   | 日付（YYYY-MM-DD） |
| startTime    | string   | 開始時間（HH:mm）  |
| endTime      | string   | 終了時間（HH:mm）  |
| place        | string   | 場所名             |
| purpose      | string   | やること・目的     |
| memo         | string   | メモ               |
| createdAt    | datetime | 作成日時           |
| updatedAt    | datetime | 更新日時           |
