# TripNote（仮）

旅行のしおりと出費をまとめて管理できるWebアプリ

---

## 概要

TripNoteは、旅行ごとの予定（しおり）と出費を一元管理できるアプリです。  
旅行中のスケジュール管理とお金の記録をまとめることで、  
「何をして・いくら使ったか」を後から振り返れることを目的としています。

---

## 想定ユーザー

- 個人で旅行を楽しむ人
- 友人や家族との旅行を記録したい人
- 旅行中の出費を把握したい人

---

## MVP（初期リリース）

本アプリは、まず以下の機能をMVPとして開発します。

- ユーザー登録
- ログイン・ログアウト機能
- 新規しおり作成（タイトル・日程）・一覧表示
- 予定の登録・表示
  - （時間、場所、出費カテゴリ一覧、費用、写真、動画、メモ、やること(目的)
- 出費の登録・合計金額の表示

※ MVPを優先して実装し、段階的に機能追加を行う想定です。

---

## 今後追加したい機能（アイデア）

- 出費のカテゴリ別集計
- 旅行の共有機能
- 写真の保存
- チェックリスト
